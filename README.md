# Student_Management_System_Project-JDBC-Swings

A desktop-based Student Management System developed using Java Swing, JDBC, and MySQL. The application provides a graphical interface to manage student records and perform CRUD operations.

## Features

- Insert student records
- Update student records
- Delete student records
- Display student records
- Custom display of selected student details
- Input validation
- MySQL database integration
- User-friendly Java Swing interface

## Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
- Eclipse IDE
- Git & GitHub

## Project Structure

- `StudentMS.java` – Main application frame
- `InsertFrame.java` – Insert student records
- `UpdateFrame.java` – Update student records
- `DeleteFrame.java` – Delete student records
- `DisplayFrame.java` – Display student records
- `CustomDisplayFrame.java` – Display selected student details
- `Student.java` – Student model class
- `StudentApp.java` – JDBC and database operations

## Database

The application uses MySQL to store student records.

The student table contains details such as:

- ID
- Name
- Course
- Marks

## How to Run

1. Clone the repository.
2. Open the project in Eclipse.
3. Create the required MySQL database and table.
4. Add the MySQL JDBC driver.
5. Configure the database connection details.
6. Run `StudentMS.java`.
